# my-locus

Source for [blog.yuzuru.me](https://blog.yuzuru.me). Hugo + Blowfish, auto-deployed to GitHub Pages on push to `main`.

```bash
mise install        # toolchain (see mise.toml)
just setup          # install prek hooks
just                # list commands
```

## Notes to self

- **Tags**: every post tag must exist in `data/tags.yaml`; CI and the prek hook reject unknown tags. Tag pages under `content/tags/` are generated by `just tags-sync`.
- **Frontmatter**: see [`docs/frontmatter.md`](docs/frontmatter.md).
- **Theme**: Blowfish is a Hugo Module (`go.mod` + `config/_default/module.toml`), not a submodule.
